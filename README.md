# 🎬 IMDB Movie Review Sentiment Analysis Using Deep Learning

## 📌 Project Overview
This project is a Deep Learning-based sentiment analysis system that classifies IMDB movie reviews as either **Positive** or **Negative**. It uses Natural Language Processing (NLP) techniques for text preprocessing and a trained deep learning model for sentiment prediction.

## 🚀 Features
- Predicts sentiment of IMDB movie reviews.
- Classifies reviews as Positive or Negative.
- Text preprocessing using tokenization and padding.
- Trained deep learning model for accurate predictions.
- Easy-to-use Jupyter Notebook implementation.

## 🛠️ Technologies Used
- Python
- TensorFlow / Keras
- NumPy
- Pandas
- Scikit-learn
- Pickle
- Jupyter Notebook

## 📊 Dataset
The project uses the **IMDB Movie Reviews Dataset** for training and evaluation.

> **Note:** The dataset is not included in this repository because of GitHub's file size limitations.

## ▶️ How to Run
1. Clone this repository.
2. Install the required libraries.
3. Open `phase1.ipynb` in Jupyter Notebook.
4. Run all cells.
5. Test the model using your own movie reviews.

## 📈 Output
The model predicts whether a movie review is:
- ✅ Positive
- ❌ Negative
